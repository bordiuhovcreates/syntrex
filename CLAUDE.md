# Лендинг на Astro (стартовий шаблон VERSTAI)

Проєкт збирається з макета Figma. Заготовки блоків у шаблоні — лише приклади: перебудовуй їх за фреймами, посилання на які я даю.

## Стек
- Astro, статичний сайт
- GSAP + ScrollTrigger для анімацій
- Публікація: GitHub Pages через GitHub Actions (`.github/workflows/deploy.yml`)
- Адмінка: Pages CMS (`.pages.yml`)
- Заявки: Google Apps Script (`google-apps-script/Code.gs`) → Telegram + Google-таблиця

## Структура
- `src/components/Block1.astro`, `Block2.astro`… — кожен блок макета в окремому компоненті, нумерація як у Figma (Блок 1, Блок 2…)
- `src/content/*.json` — усі тексти, посилання й шляхи до зображень
- `src/styles/variables.css` — кольори, стилі тексту, відступи, радіуси
- `src/styles/global.css` — скидання, контейнер, типографіка, кнопка
- `src/scripts/animations.js` — анімації через атрибути `data-anim`, `data-count`
- `src/scripts/interactive.js` — бургер-меню і попап
- `src/components/LeadForm.astro` — форма заявки, `Popup.astro` — попап з формою
- `public/images` — зображення (сюди ж їх завантажує адмінка)
- `site.config.mjs` — адреса сайту (SITE_URL, BASE_PATH) і адреса форми (FORM_ENDPOINT)

## Правила
- Тексти і зображення — тільки у файлах `src/content`, ніколи не вписуй їх у компоненти. Інакше їх не можна буде змінити в адмінці.
- Додаєш новий текст, список чи зображення — одразу додай поле в `.pages.yml` з підписом українською, зрозумілим для клієнта.
- Кольори, розміри шрифтів і відступи — тільки через змінні з `variables.css`. Нових значень у коді не вигадуй; якщо в макеті є нове значення — додай змінну.
- Усі внутрішні посилання і шляхи до зображень — через `url()` з `src/lib/url.ts`, щоб сайт працював і на github.io/назва-репозиторію, і на своєму домені.
- Mobile-first адаптив, мобільний макет — 390 px. Перевіряй, щоб не було горизонтального скролу.
- Анімації: використовуй `data-anim="fade-up" | "fade" | "stagger"` і `data-count`. Нові ефекти додавай в `animations.js` так само через атрибути. Для reduced motion анімації вимкнені.
- Будь-яка кнопка з `data-popup-open="Назва форми"` відкриває попап, назва потрапляє в заявку.
- Форми — тільки через `LeadForm.astro`: дані йдуть як text/plain JSON (name, phone, service, website-пастка).
- Зображення: `loading="lazy"` для всього, крім першого екрана; вказуй width і height.
- Після кожного готового блоку роби коміт з коротким описом українською.
